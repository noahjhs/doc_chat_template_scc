Get started

The easiest way: let Casper's guide set it up with you.

Begin setup with Casper's guide →

Or do it yourself, in three steps. On a Mac or a Windows PC?

  1. Download Casper for Mac

    It's small, signed and notarized. Download Casper.zip →

  2. Open it

    Unzip, open Casper, and click Open if macOS asks. Casper appears in your menu bar. If it asks about opening at login, say yes — friends' mirrors only work while Casper runs.

  3. Download Casper for Windows

    It's small and installs just for you, with no administrator password. Download Casper-Setup.exe →

  4. Run it

    Open the file you downloaded. Casper is new, so Windows may say Windows protected your PC: click More info, then Run anyway. Casper appears as a ghost in the tray, bottom right (it may sit behind the ^). If it asks about starting with Windows, say yes — friends' mirrors only work while Casper runs.

  5. Create your account

    On the same computer: sign up → That connects this computer to you, and Casper's guide picks up from there.
